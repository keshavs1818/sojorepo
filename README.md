# Sourjya's Math Studio

A small Streamlit practice site for concept-first math instruction. The draft focuses on:

- Reading dates such as `11.22.2009` as November 22, 2009
- Choosing addition, subtraction, multiplication, or division from a story
- Understanding equal groups and the difference between `0 + 2` and `0 x 2`
- Short word problems with an explanation before calculation
- A Wednesday 7:00 PM lesson sequence beginning September 16, 2026

## Run locally

```powershell
pip install -r requirements.txt
streamlit run app.py
```

The schedule and activities are intentionally a rough draft so they can be adjusted to Sourjya's pace and interests.
